# Вихідний код гри + паперова версія на 40 хв

`paper/` — повне джерело гри: YAML справи, рушій застосунку, документи, карти й розв'язувач. Сюди додано **окрему паперову партію на 40 хв без застосунку**. Розгорнутий застосунок у корені репозиторію (`index.html`, `assets/`, `sw.js`, `img/`) не змінювався, і його збірка (`vite.config.ts`, `npm run build`) теж лишилась як була.

## Що додано

| Файл | Що це |
|---|---|
| `content/cases/astrolabe/paper40.yaml` | Що лишити й як розкласти: конверти й аркуші, завдання, шлюзи, події, картки рішень, сценарій, тексти для паперу, правила |
| `tools/paper/content.ts` | YAML справи + `paper40.yaml` → `app/src/generated/paper40.json` (усі тексти розгорнуто) |
| `tools/paper/build-paper.ts` | Рендерить PDF через Chromium і перевіряє, що нічого не вилізло за аркуш і не обрізано |
| `app/paper.html`, `app/vite.paper.config.ts`, `app/src/paper/*` | Сторінки друку: комплект, пачка ведучого, посібник, бланки, правила |
| `app/src/paper/epilogue.ts` | Епілог і рахунок для паперу (бонус за час — від 40 хв) |
| `app/src/paper/paper.test.ts` | Перебирає понад 10 000 варіантів партії: паперовий епілог збігається з `engine/epilogue.ts`. Також перевіряє вміст: немає застосунку, QR і кодів АС-###, кожне завдання має свої документи в конвертах до нього, хронометраж ≤ 40 хв |

`app/public/img` — посилання на `../../../img` (ті самі фото, що використовує застосунок).

## Команди

```bash
npm ci
npm test            # усі тести, разом із паперовими
npm run paper       # PDF у ../print
```

Якщо Playwright не знаходить свій браузер, вкажіть шлях до Chromium, наприклад:

```bash
CHROMIUM_PATH=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome npm run paper
```
